# 한글 작명 생성기 — 이름, 마음을 담다 (디자인 반영판)

## 실행 방법
1. ZIP 파일의 압축을 풉니다.
2. `hangeul_naming_site` 폴더 안의 `index.html`을 Chrome 또는 Edge에서 엽니다.
3. 메인 화면에서 `작명 시작하기`를 누르고 원하는 이름의 느낌을 입력합니다.
4. 추천 카드에서 `마음에 담기`를 누른 뒤 최종 선택 화면에서 인쇄할 수 있습니다.

## 파일 구성
- `index.html`: 메인·입력·추천·최종 결과 4개 화면
- `style.css`: 시안의 색상, 카드, 반응형 및 인쇄 디자인
- `script.js`: 키워드 분석, 추천, 중복 방지, 선택 목록, 브라우저 저장, 인쇄
- `data.js`: 한글 이름 데이터
- `assets/`: 시안에서 추출한 풍경·도우미 이미지

## 실행 및 배포
별도 서버, 설치 프로그램, 외부 AI API가 필요하지 않습니다. `index.html`을 브라우저에서 열면 실행됩니다. GitHub Pages에 게시할 때는 폴더 안의 모든 파일과 `assets` 폴더를 함께 저장소에 올립니다.

## 작동 방식과 범위
- 입력 문장에서 맑음·따뜻함·자연스러움·세련됨·밝음·부드러움·단정함 등의 키워드를 찾고, `data.js`의 이름을 우선순위화합니다.
- 한 번에 이름 2개를 추천합니다. 이미 추천한 이름은 중복 추천하지 않습니다.
- 추천 및 선택 이력은 브라우저 `localStorage`에 저장됩니다. 브라우저 데이터 삭제, 시크릿 모드, 다른 기기에서는 이어지지 않습니다.
- 성씨는 추천 카드와 최종 결과에 함께 표시합니다. 이름 유형은 추천 우선순위에 반영됩니다.
- 현재 데이터는 대부분 두 글자 이름입니다. 세 글자 이름은 데이터가 추가되기 전까지 충분히 추천되지 않을 수 있습니다.
- 본 웹사이트는 생성형 AI가 아니며, 사전 데이터와 규칙을 이용하는 오프라인형 작명 보조 도구입니다. 이름의 뜻과 어원은 일반적인 연상 설명이며 공식 어원·법적 사용 적합성을 보증하지 않습니다.

## 이름 데이터 추가
`data.js`의 `NAME_DATA` 배열에 아래 구조로 항목을 추가합니다.

```js
{
  name: "새이름",
  meaning: "이름이 주는 의미 또는 연상",
  tone: ["맑음", "따뜻"],
  description: "이름의 어감과 특징"
}
```

사용 가능한 분위기 분류 예시: `맑음`, `따뜻`, `자연`, `세련`, `밝음`, `부드러움`, `단정`
